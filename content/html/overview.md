# HTML — Overview

**HTML (HyperText Markup Language)** היא שפת סימון המשמשת להגדרת **המבנה והתוכן של דפי אינטרנט**.

HTML לא נחשבת לשפת תכנות: היא לא מיועדת לכתוב לוגיקה כמו תנאים, לולאות או פונקציות. התפקיד שלה הוא לתאר לדפדפן **אילו רכיבים קיימים בדף ומה המשמעות שלהם**.

## התפקיד של HTML באתר

בפיתוח Web נהוג לחלק את האתר לשלוש שכבות עיקריות:

- **HTML** — מבנה ותוכן.
- **CSS** — עיצוב ומראה.
- **JavaScript** — התנהגות ולוגיקה.

כלומר, HTML מגדיר *מה קיים בדף*, CSS מגדיר *איך הוא נראה*, ו־JavaScript מגדיר *איך הוא מתנהג*.

## איך HTML בנוי?

HTML בנוי מ־**Elements**. רוב האלמנטים מוגדרים באמצעות **Tags**, ואלמנטים יכולים להיות מקוננים זה בתוך זה באמצעות **Nesting**.

לדוגמה, אלמנט פשוט נראה כך: `<tagname>Content</tagname>`.

בהמשך נלמד את סוגי האלמנטים השונים, את מבנה מסמך HTML, Attributes, טקסט, קישורים, תמונות, טבלאות, Forms ועוד.

## מבנה מסמך HTML

לכל מסמך HTML יש מבנה בסיסי שמגדיר את המסמך עצמו, מידע עליו, ואת התוכן שמוצג למשתמש.

את המבנה המלא נלמד בפרק **Document Structure**.

## Semantic HTML

HTML לא מתאר רק איך לחלק את הדף, אלא גם **מה המשמעות של כל חלק**. בחירה נכונה של אלמנטים עוזרת לקריאות הקוד, לנגישות ולמנועי חיפוש.

נלמד את הנושא בהרחבה בפרק **Semantic HTML & Navigation**.

## הרעיון המרכזי

HTML הוא **השלד של דף האינטרנט**. הוא מגדיר את מבנה הדף ואת המשמעות של התוכן, ועל המבנה הזה CSS ו־JavaScript מוסיפים עיצוב והתנהגות.
