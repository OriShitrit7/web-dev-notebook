## הרצה מקומית

**לחיצה כפולה על `start.command`** בתיקיית הפרויקט. זה מרים שרת מקומי ופותח את
הדפדפן אוטומטית. לעצירה: `Ctrl+C` או סגירת חלון ה־Terminal שנפתח.

לחלופין, ידנית:

```bash
python3 -m http.server 8000
```

ואז לפתוח `http://localhost:8000`.

> אם שינויים לא מופיעים אחרי רענון — זה cache של הדפדפן. רענון קשיח:
> `Cmd+Shift+R` (macOS) או `Ctrl+Shift+R` (Windows).

### למה צריך שרת ולא פשוט לפתוח את index.html?

שתי סיבות, ושתיהן לא ניתנות לעקיפה בלי לשנות את מבנה הפרויקט:

1. **`fetch` חסום ב־`file://`.** `app.js` טוען את הפרקים בזמן ריצה
   (`fetch('content/html/overview.md')`). כשפותחים קובץ בלחיצה כפולה הדפדפן
   מתייחס אליו כ־origin אטום וחוסם קריאה לקבצים שכנים — הגנת אבטחה, לא באג.

2. **הספריות מגיעות מ־CDN.** `index.html` טוען את `marked` (שממיר את ה־Markdown
   ל־HTML) ואת `highlight.js` מרשת. בלי `marked` הדף יישאר ריק, גם אם סעיף 1 היה נפתר.

בפועל זה לא מפריע: **ב־GitHub Pages הכול עובד רגיל**, כי שם האתר מוגש ב־HTTP.
השרת המקומי נחוץ רק כדי לראות שינויים *לפני* שדוחפים אותם.

### בלוקים

> **כלל הזהב של הפרק:** חוץ מכותרות ומפסקת ה־`lead` בראש הפרק, **שום טקסט לא יושב
> ישירות על רקע האתר**. כל פסקה נמצאת בתוך `box` כלשהו. זה מה שעושים גם בדשבורד ה־DS/ML.
> לפסקה רגילה בלי כותרת משתמשים ב־`box` בלי `box-head`:
>
> ```html

> </div>
> ```

| רכיב | שימוש |
| --- | --- |
| `<p class="lead">` | פסקת פתיחה לפרק — **הדבר היחיד שמותר לו להיות בלי מסגרת** |
| `<div class="box">` | פסקה רגילה במסגרת, בלי כותרת |
| `<div class="box theory">` | הגדרה / תיאוריה (כחול) |
| `<div class="box example">` | דוגמה / תובנה (ירוק) |

### שתי מלכודות בכתיבה

1. **בתוך בלוק HTML גולמי אסור להשאיר שורה ריקה.** שורה ריקה סוגרת את הבלוק,
   וכל מה שאחריה ייצא מהקופסה. גם המשמעות נגזרת מכך: בתוך `box-body` כותבים
   HTML (`<p>`, `<ul>`, `<strong>`, `<code>`) ולא Markdown.

   > **איך מזהים את זה:** פתאום מופיע באמצע הפרק **בלוק קוד שחור** עם קוד ה־HTML
   > או ה־SVG שלך בתוכו, ולפעמים עם תווית שפה אקראית כמו `PHP-TEMPLATE`.
   > זה בדיוק הסימן — יש שורה ריקה בתוך בלוק HTML קצת מעליו.

2. **קוד HTML בתוך טקסט נכתב עם entities**: `&lt;p&gt;` ולא `<p>`, אחרת הדפדפן
   יפרש אותו כתגית אמיתית. בתוך בלוקי ``` אין צורך — שם זה אוטומטי.
